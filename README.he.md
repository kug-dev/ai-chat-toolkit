# AI Chat Toolkit

**English:** [README באנגלית](README.md)

ערכת כלים מקומית לגיבוי, חיפוש נושאים וזיהוי קשרים בין שיחות עם עוזרי AI.

הפרויקט כולל שני כלים שאפשר להשתמש בהם בנפרד או ביחד:

1. **AI Chat Backup** — סקריפט לדפדפן (Tampermonkey/Violentmonkey) שמייצא שיחות ואת הקבצים והתוצרים הזמינים.
2. **Chat Topic Finder** — יישום Python שמנתח גיבויים, מוצא שיחות שעוסקות ברעיונות דומים, מזהה הסתעפויות של שיחות ומפיק דוח HTML וקובצי נתונים.

## תכונות

### גיבוי שיחות

- מתאמים נפרדים עבור ChatGPT, Claude ו-Gemini.
- ייצוא JSON גולמי ותמלול Markdown, כאשר האתר מאפשר זאת.
- שמירת תוצרים, קבצים מצורפים, קובצי קוד ומדיה שנוצרה — בהתאם למה שהאתר עדיין מספק.
- ייצוא ZIP בחלקים, מסנני סוגי קבצים, ניסיונות חוזרים והיסטוריית גיבוי.
- ממשק באנגלית ובעברית וצופה מקומי לעיון בגיבוי ללא חיבור לאתר.

הסקריפט מופץ כקובץ עצמאי אחד: `browser/dist/ai-chat-backup.user.js`.

### איתור נושאים בשיחות

- קריאת קובצי ZIP, קובצי `chat.md`, קובצי `raw.json`, Markdown וקובצי טקסט.
- התאמת שיחות באמצעות TF-IDF ומאפיינים לשוניים; אפשר להוסיף ניתוח באמצעות מודל AI מקומי או מרוחק.
- קיבוץ שיחות לפי נושאים משותפים.
- **השוואת מקטעים תואמים:** בעת פתיחת זוג שיחות בדוח, מוצגים תחילה קטעים שנבחרו מתוך גוף השיחה המלא לפי מונחי ההתאמה המשותפים. לאחר מכן אפשר לפתוח גם את קטעי ההקשר מתחילת השיחות.
- זיהוי הסתעפויות: שיחות בעלות תחילית מתועתקת משותפת ומסודרת, שלאחריה כל שיחה ממשיכה בכיוון אחר. דמיון בנושא בלבד אינו נחשב להסתעפות.
- חיפוש מלא באמצעות SQLite FTS5, כאשר גרסת SQLite תומכת בכך.
- הפקת דוח HTML אינטראקטיבי, קובצי CSV ו-JSON, מסד נתונים SQLite ורשימת תיקון לגיבויים חסרים.
- ממשק ודוחות באנגלית ובעברית.

### סינון שיחות שמכילות מדיה שנוצרה בלבד

אפשר להחריג שיחות שבהן נשמרו קובצי מדיה שנוצרו (למשל תמונה, וידאו או שמע), אך לא נמצא בתמלול טקסט משמעותי.

הסינון שמרני: שיחה שכוללת הנחיה כתובה כגון "צור תמונה של חתול" **לא** תסווג כשיחת מדיה בלבד, גם אם נוצר ונשמר בה קובץ תמונה.

ברירת המחדל היא לכלול את כל השיחות.

## התקנה והרצה

נדרשת Python 3.10 ומעלה. לניתוח הבסיסי אין תלות חובה בחבילות צד שלישי.

מתוך עותק מקומי של המאגר:

```bash
python -m chat_topic_finder
```

ייפתח ממשק גרפי. בחרו קובץ גיבוי ZIP אחד או יותר, או תיקייה שבה נמצאים הגיבויים.

להרצה ללא ממשק גרפי:

```bash
python -m chat_topic_finder --input /path/to/backup.zip --output /path/to/report
```

להחרגת שיחות שמכילות מדיה שנוצרה בלבד:

```bash
python -m chat_topic_finder --input /path/to/backup.zip --output /path/to/report --exclude-generated-media-only
```

לרשימת כל האפשרויות:

```bash
python -m chat_topic_finder --help
```

## ספקי AI אופציונליים

התאמת שיחות, יצירת אינדקס, זיהוי הסתעפויות והפקת דוחות פועלים גם ללא מודל AI.

אפשר להגדיר ספק מקומי או מרוחק, למשל Ollama, או API התואם ל-OpenAI Chat Completions. יש להגדיר את כתובת השירות, שם המודל ומפתח API לפי הצורך.

**פרטיות:** כאשר מגדירים ספק AI מרוחק, קטעים מתוכן השיחות נשלחים לאותו ספק לצורך הניתוח. אין שליחה אוטומטית לספק מרוחק כאשר ניתוח AI לא הוגדר. עבור ארכיונים רגישים עדיף להשתמש במודל מקומי.

## זיהוי הסתעפויות

הזיהוי מופעל כברירת מחדל וניתן לביטול באמצעות:

```bash
python -m chat_topic_finder --input /path/to/backup.zip --no-branch-matching
```

זיהוי הסתעפות דורש כמה תורות עוקבים שתואמים לפי תפקיד וסדר, תחילית משותפת משמעותית, והמשך שונה בכל אחת מהשיחות. התוצאות הן מועמדים היוריסטיים ולא הוכחה ודאית.

הדוח כולל:

- `branch_matches.csv` — זוגות שיחות ומדדי התחילית המשותפת.
- `branch_families.json` — קבוצות של שיחות מועמדות להסתעפות.
- מקטע ייעודי בדוח HTML.

## קובצי הפלט

בדרך כלל ייווצרו בתיקיית הפלט:

- `topic_report.html` — דוח אינטראקטיבי עם קבוצות, מסננים, ציר פעילות וסייר שיחות.
- `chat_index.csv` — אינדקס שיחות ומאפייניהן, כולל זיהוי שיחות מדיה בלבד.
- `similar_pairs.csv` — זוגות שיחות דומות.
- `analysis.json` — נתוני הניתוח.
- `branch_matches.csv` ו-`branch_families.json` — נתוני הסתעפויות.
- `index.sqlite` — אינדקס וחיפוש טקסט מלא.
- `retry_chat_ids.json` — מזהי שיחות שבהן נמצאו קבצים חסרים או שגיאות.

## בנייה ובדיקות

בניית קובץ המשתמשסקריפט:

```bash

```

```bash

python -m unittest discover -s tests -v
node --check browser/dist/ai-chat-backup.user.js
```
